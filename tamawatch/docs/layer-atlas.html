TamaWatch Layer Atlas

Every pixel on the watch face is a stack. This maps that stack twice — how the art is baked ahead of time, and how it is composited live — and shows the single seam that joins the two.

asset generation (offline, Python) runtime (on-watch, Compose) the annoyed-mood layer the seam: generated PNG + manifest
PHASE ①

Asset generation

Nothing is drawn by hand. Python generators paint every sprite, icon, background and sound, then generate_assets.py validates the set and writes it into the app — frame-strip PNGs plus a manifest of geometry and tags.

PHASE ②

Runtime composition

On the watch, Jetpack Compose stacks eight layers back-to-front into the Home screen every frame. SpriteBank slices frames out of the generated sheets on demand; the pet’s live state decides which frame and which overlays each layer shows.

◆

The two phases meet at one seam. Phase ① writes exactly two things the runtime reads back — the frame-strip PNGs and the manifest that indexes them. SpriteBank is the only bridge across it: change the art and nothing in Phase ② moves; change the manifest’s geometry and every layer that draws a sprite re-slices correctly, because no frame size is ever hard-coded.
